# HelloAO normalization fixtures

`helloao-verse-fixtures.json` contains 632 real BSB and World English Bible verses.
`content` is copied from the standard API; `expected` is the provider's corresponding
simplified verse text, not text generated by this app.

Sources:

- https://bible.helloao.org/api/BSB/complete.json
- https://bible.helloao.org/api/BSB/complete.simple.json
- https://bible.helloao.org/api/ENGWEBP/complete.json
- https://bible.helloao.org/api/ENGWEBP/complete.simple.json

Coverage includes all verses in Genesis 1, Psalm 23, Matthew 5, and John 3, plus
the first three verses of the first chapter of every book, in both translations.
The translations are public domain; see the repository's third-party notices.

The normalization rules were checked against the official generator:
https://github.com/HelloAOLab/bible-api/blob/main/packages/helloao-tools/generation/simple.ts

An independent full-corpus comparison of those rules against the published simplified
responses matched all 31,086 BSB and 31,103 WEB verses, including 22,494 verses
containing structured fragments. The Kotlin regression suite checks these representative
fixtures plus focused marker, poetry, line-break, and punctuation cases offline.
