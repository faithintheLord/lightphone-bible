# Submission route

Light now accepts submissions in the [Dashboard](https://dashboard.thelightphone.com/): Settings → Account → Developer Account → Manage Custom Tools → Submit New Tool.

The old intent-issue process is no longer needed. Use [SUBMISSION.md](../SUBMISSION.md) and [the listing copy](STORE_LISTING.md). Light checks package-name availability when registering the tool. Do not claim registration or approval until the dashboard confirms it.
